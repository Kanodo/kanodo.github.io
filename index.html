Kanodo

A native macOS kanban app built for focus and flow. Cards open in dedicated windows for side-by-side work. Mini boards nest inside cards to break down complex tasks. Fully offline, local data, no accounts.

Windows, Not Modals

Each card expands into its own window. Compare tasks side by side, edit without losing context, multitask effortlessly on macOS.

Mini Boards Inside Cards

Break complex work into nested subtasks with full kanban boards within cards. Organize deeply without overwhelming your main view.

Workspaces and Drag-and-Drop

Separate projects across workspaces. Intuitive boards, columns, and drag-and-drop keep everything organized and accessible.

Rich Tools, Local Control

Markdown editor with images, three date types, color labels, file attachments, global search, dashboards, and ICS export. Light, dark, or system mode. All data stays local.

How It Works

1. Create a Workspace

Set up dedicated spaces for projects, teams, or personal work. Add boards and columns tailored to your workflow.

2. Build with Cards

Drag cards between columns. Open any card in its own window. Embed a mini board for subtasks, notes, dates, labels, and attachments.

3. Work Side by Side

Multiple windows let you reference tasks without switching. Search globally, filter by labels, view dashboards for progress.

4. Export and Access

Pin favorites, export to calendar, stay offline. Everything syncs locally or via iCloud—no servers, no signups.

FAQ

Is data stored securely?

Yes. All data is local on your Mac. Optional iCloud for backups. No cloud accounts or external servers required.

Does it require an internet connection?

No. Fully offline capable. Works anywhere, anytime.

Can I customize appearances?

Supports light, dark, and system modes. Color-coded labels and pinning for quick access.
